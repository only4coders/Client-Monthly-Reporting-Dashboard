# Client Monthly Reporting Dashboard

A fast, static client reporting dashboard for monthly SEO, Google Business Profile, and event-booking performance.

## Updating reports

Add or update a monthly record in `data.js`, then add its month key to the relevant client's `months` array. The interface automatically populates the selectors, KPI cards, trends, and attribution views.

## Deploy

Import this repository into Vercel as a static project. No build command or environment variables are required.
